3) Scope and exclusions
-----------------------
These are portable arithmetic/parser and simulated state-machine tests. The
slow-storage and write-failure cases are modeled using a test-only recorder and
condition-variable gate; they are not tests of the actual Windows JPEG worker,
Win32 file flush/rename semantics, or a physical storage device. The 48 reader
threads exercise immutable clock evaluation, not the Windows SRWLOCK hook path.

No Windows x64/x86 compile, GitHub Actions run, game injection, Direct3D,
Vulkan, OpenGL, GPU/driver, real-time storage, high-resolution, weak-hardware,
or long-recording runtime test was performed in this environment.
